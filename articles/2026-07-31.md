#### 기술 분석
1. **타입 정의 및 UI Props 확장**:
   - `SharedEvent` 인터페이스에 `isOwner: boolean` 필드를 추가하여 서버 응답 데이터의 권한 상태를 타입 세이프하게 관리하도록 변경했습니다.
   - `SharedScheduleItem` 컴포넌트의 Props에 `isOwner`를 추가하고 기본값을 `false`로 설정하여, 소유자 여부에 따라 UI 및 액션 버턴의 노출 상태를 제어할 수 있는 기반을 마련했습니다.

2. **API 레이어 확장**:
   - `eventShareApi`에 `deleteEventParticipants` 메소드를 추가하여 특정 이벤트의 참가자를 삭제하거나 탈퇴를 처리할 수 있는 DELETE 엔드포인트를 연결했습니다.

웹 서비스 성능 지표(Lighthouse) 개선과 검색 엔진 최적화(SEO)를 목표로 웹 앱 진입점 전반에 대한 구조적 리팩토링을 수행했습니다.

#### 기술 분석
1. **SEO 및 검색 엔진 노출 최적화**:
   - `index.html` 내 OpenGraph, Twitter, JSON-LD 구조화 데이터 메타 태그를 명확히 정의하고, 빌드 시 `VITE_SITE_URL` 기반으로 `robots.txt` 및 `sitemap.xml`을 자동 생성하도록 구성했습니다.
   - 라우트 단위 메타 태그 구성을 위해 `PageMeta` 컴포넌트를 신설하여, 404 및 로그인 후 비공개 페이지에는 `noIndex` 설정을 적용했습니다.

2. **번들 최적화 및 코드 스플리팅**:
   - 기존 모듈 로드 시점에 라우터를 생성하던 구조를 함수형(`getAuthRouter`, `getMainRouter`)으로 변경하여, 로그아웃 진입 시 무거운 메인 서비스 청크가 다운로드되던 이슈를 해결했습니다.
   - `react-big-calendar`, `moment`, Kakao Maps SDK 등 용량이 큰 라이브러리가 포함된 메인 페이지를 `lazy()`로 분리하여 **랜딩 진입 JS 번들 용량을 1,207kB에서 450kB로 62.7% 감축**했습니다.

3. **초기 렌더링 성능 향상**:
   - HTTP-only 쿠키로 인해 클라이언트에서 읽을 수 없던 인증 상태를 `AUTH_HINT_KEY` (`calio.isLoggedIn`) 힌트 값으로 일차 판단하여 `/members/me` API 응답 전달까지 첫 렌더링이 블로킹되던 문제를 해소했습니다.
   - Emotion Global에서 로딩하던 웹폰트를 `index.html` 내 `preconnect`/`preload`/`font-display: swap` 적용으로 변경하여 LCP 및 폰트 플리커 현상을 개선했습니다.

4. **빌드 파이프라인 대응**:
   - Vite 7 요구사항에 맞춰 GitHub Actions Node 버전을 18에서 20.19+ 로 올바르게 업데이트했습니다.

  noIndex?: boolean
}

const SITE_NAME = 'Calio'

export default function PageMeta({ title, description, canonicalPath, noIndex }: PageMetaProps) {
  useEffect(() => {
    document.title = `${title} | ${SITE_NAME}`
    // 동적 meta 태그 갱신 로직 처리
  }, [title, description, canonicalPath, noIndex])

  return null
}

const AUTH_HINT_KEY = 'calio.isLoggedIn'

const readAuthHint = () => {
  if (typeof window === 'undefined') return false
  try {
    if (window.location.pathname.startsWith('/login')) return false
    return localStorage.getItem(AUTH_HINT_KEY) === 'true'
  } catch {
    return false
  }
}
