#### 1. AI 챗봇 API 및 데이터 타입 정의
자연어 처리(NLP) 서버와의 원활한 통신을 위해 `nlpApi`를 신설하고, 챗봇의 다양한 액션 상태와 스케줄 타입을 명확히 구분할 수 있도록 인터페이스를 설계했습니다.

*   **`src/shared/api/home/home.ts`**
    ```typescript
    export const nlpApi = {
      sendMessage: async (message: string): Promise<ChatResponse> => {
        const res = await axiosInstance.post<ChatResponse>('/chat', { message })
        return res.data
      },
    }
    ```
    *   **분석**: 단일 텍스트 메시지를 인자로 받아 `/chat` 엔드포인트로 `POST` 요청을 보내는 구조입니다. 이를 통해 사용자의 자연어 입력을 백엔드 NLP 엔진으로 전달합니다.

*   **`src/shared/types/home/home.ts`**
    ```typescript
    // 챗봇 관련 type
    export type ChatActionType = 'CREATED' | 'UPDATED' | 'DELETED' | 'CLARIFYING' | 'NONE'
    export type ScheduleType = 'EVENT' | 'TODO'

    export interface ChatRequest {
      message: string
    }

    export interface ChatResponseResult {
      reply: string
      action: ChatActionType
      scheduleId: number | null
      recurrenceGroupId: number | null
      scheduleType: ScheduleType | null
    }
    ```
    *   **분석**: 챗봇의 응답 결과에 따라 캘린더 일정이 생성(`CREATED`), 수정(`UPDATED`), 삭제(`DELETED`)되거나 추가 질문(`CLARIFYING`)이 필요한 상황을 `ChatActionType` 유니온 타입으로 세분화했습니다. 이는 챗봇의 답변이 단순 텍스트에 그치지 않고 서비스 내 실제 스케줄링 액션과 유기적으로 결합될 수 있도록 돕는 훌륭한 설계입니다.

#### 2. `AIChatModal` 컴포넌트 구현 및 성능 최적화
사용자와의 인터랙션이 잦은 AI 챗봇 모달의 UI 구조를 개선하고 비주얼 요소를 보강했습니다.

*   **`src/features/Common/AIChatModal.tsx`**
    ```typescript
    import { useQueryClient } from '@tanstack/react-query' // 1. useQueryClient 임포트
    import React, { useEffect, useRef, useState } from 'react'

    import { nlpApi } from '@/shared/api/home/home'
    import ChatIcon from '@/shared/assets/icons/chat.svg'
    import RobotIcon from '@/shared/assets/icons/robot.svg'
    import type { ChatMessage } from '@/shared/types/home/home'
    ```
    *   **분석**: `@tanstack/react-query`와의 통합을 준비하기 위해 `useQueryClient`를 도입했으며, 새롭게 추가된 로봇 및 채팅 아이콘 에셋을 바인딩하여 시각적 완성도를 높였습니다.

*   **`src/features/Common/AIChatModal.styles.ts`**
    ```typescript
    export const Container = styled.div`
     position: absolute;
     top: 70px;
     right: 0;
    -  width: 450px;
    -  height: 430px;
    +  width: 500px;
    +  height: 400px;
     z-index: 999;
    +  will-change: transform, opacity;
     
      ${media.down(theme.breakPoints.desktop)} {
        position: relative;
        top: 0;
        right: 0;
        width: 100%;
    -    height: auto;
    +    height: 430px;
        margin: 20px 0;
        z-index: 1;
        box-shadow: none;
    ```
    *   **분석**: 
        1.  **치수 조정**: 데스크톱 환경에서 모달의 가로 폭을 넓히고(`450px` -> `500px`) 세로 높이를 소폭 줄여(`430px` -> `400px`) 텍스트 가독성을 확보했습니다.
        2.  **렌더링 최적화**: `will-change: transform, opacity;` 속성을 추가했습니다. 모달이 열리고 닫힐 때 발생할 수 있는 브라우저의 리페인트(Repaint) 및 리플로우(Reflow) 연산을 최소화하고 GPU 가속을 유도하여, 저사양 기기에서도 부드러운 애니메이션을 보장하도록 조치했습니다.
        3.  **반응형 대응**: 모바일/태블릿(Desktop Down) 환경에서 높이 값을 `auto`에서 `430px` 고정값으로 명시하여, 모바일 뷰포트 내에서 스크롤 영역이 무너지는 현상을 방지했습니다.
