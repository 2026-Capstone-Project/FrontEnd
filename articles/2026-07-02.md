# [2026년 07월 02일] 신규 랜딩 페이지 도입 및 캘린더 아키텍처 대규모 리팩터링

오늘 우리 Calio 팀은 서비스의 첫인상을 결정짓는 신규 랜딩 페이지를 성공적으로 구현 및 안착시켰으며, 그동안 복잡하게 얽혀있던 캘린더 도메인의 디렉터리 구조와 임포트 경로를 대대적으로 정리하는 리팩터링 작업을 진행했습니다. 

신규 유저 유입을 위한 프런트엔드 UI/UX 고도화와 장기적인 유지보수성 확보를 위한 코드베이스 체질 개선이 동시에 이루어진 뜻깊은 하루였습니다. 오늘 진행된 상세 작업 내역과 기술적 분석을 공유합니다.

### [Yeonjin Kim] fix: 랜딩 페이지 리뷰 반영
최초 구현 이후 진행된 코드 리뷰 피드백을 신속하게 반영하여 UI 버그 수정 및 웹 접근성(A11y)을 개선했습니다.

*   **반응형 레이아웃 대응 및 웹 접근성 강화 (`src/pages/auth/Landing.styles.ts`)**
    기존 네비게이션 바의 고정 최소 너비(`min-width: 1000px`)를 제거하고 `width: 100%`로 변경하여 소형 디바이스 및 태블릿 환경에서의 레이아웃 깨짐 현상을 방지했습니다.
    또한, 애니메이션에 민감한 사용자를 배려하여 시스템 설정에서 동작 줄이기(`prefers-reduced-motion`)를 활성화한 경우 로봇 아이콘의 애니메이션을 비활성화하도록 미디어 쿼리를 추가했습니다. 시니어 개발자로서 이러한 디테일한 접근성 고려는 매우 훌륭한 프랙티스라고 판단합니다.
    ```css

      font-size: 15px;
      font-weight: 700;
      max-width: 1040px;
    -  min-width: 1000px;
    +  width: 100%;
      margin: 84px auto 0;
    
    ...
    
    +  @media (prefers-reduced-motion: reduce) {
    +    animation: none;
    +
    +    &::after {
    +      animation: none;
    +    }
    +  }
    ```

### 💡 시니어 개발자 총평
