#### 1. 에셋 디렉터리 구조 표준화 및 임포트 경로 최적화
기존에 `@/assets/icons/`와 `@/shared/assets/icons/`에 파편화되어 존재하던 공통 아이콘(chevron, plus, rotate, trash, check, close, search 등)을 `@/assets/icons/common/` 경로로 일원화하였습니다. 또한 소셜 로그인 아이콘들을 `@/assets/social/` 폴더로 이동시키고 배경 유무에 따른 에셋(`_withBack.svg`)을 명확히 분리하여 컴포넌트 간의 의존성을 단순화했습니다.

* **LoginCard.tsx의 임포트 경로 변경 예시**:
```typescript
// 변경 전
import GoogleIcon from '@/assets/icons/google.svg?react'
import KakaoIcon from '@/assets/icons/kakao.svg?react'
import NaverIcon from '@/assets/icons/naver.svg?react'

// 변경 후
import GoogleIcon from '@/assets/social/google.svg?react'
import KakaoIcon from '@/assets/social/kakao.svg?react'
import NaverIcon from '@/assets/social/naver.svg?react'
```

* **공통 아이콘 임포트 경로 변경 예시 (TodoCard.tsx)**:
```typescript
// 변경 전
import Repeat from '@/shared/assets/icons/rotate.svg?react'
import Trash from '@/shared/assets/icons/trash-2.svg?react'

// 변경 후
import Repeat from '@/assets/icons/common/rotate.svg?react'
import Trash from '@/assets/icons/common/trash-2.svg?react'
```

#### 2. AI 플로팅 버튼(`AIChatModalButton`) 구현 및 페이지 이식
사용자가 서비스 이용 중 언제든지 AI의 도움을 받을 수 있도록 화면 우측 하단에 고정되는 플로팅 버튼 컴포넌트를 신규 개발했습니다. 이를 캘린더 페이지(`CalendarPage.tsx`)와 투두 리스트 페이지(`TodoListPage.tsx`)에 배치하여 접근성을 대폭 향상시켰습니다. 또한 모바일 환경에서 모달이 화면을 침범하지 않도록 `isCompact` 프롭을 추가하여 패딩 및 섀도우 스타일을 동적으로 조절할 수 있게 설계했습니다.

* **AIChatModalButton.style.ts**:
```typescript
import styled from '@emotion/styled'
import { media } from '@/shared/styles/media'
import { theme } from '@/shared/styles/theme'

export const Wrapper = styled.div`
  position: fixed;
  right: 40px;
  bottom: 100px;
  z-index: 1000;
  ${media.down(theme.breakPoints.desktop)} {
    right: 20px;
    bottom: 20px;
  }
`

export const AIChatButton = styled.button`
  width: 54px;
  height: 54px;
  display: flex;
  justify-content: center;
  align-items: center;
  // 이하 스타일 생략
`
```

* **AIChatModal.styles.ts (반응형 대응)**:
```typescript
interface ContainerProps {
  isCompact?: boolean
}

export const Container = styled.div<ContainerProps>`
  display: flex;
  flex-direction: column;
  background: ${theme.gradients.ai2};
  border-radius: 30px;
  padding: 24px;
  box-shadow: 0px 10px 30px rgba(0, 0, 0, 0.1);
`
```

#### 3. 모바일 CSS 깨짐 해결 및 스타일 리팩토링
* **반응형 미디어 쿼리 표준화**: `Friend.styles.ts` 등에서 사용되던 하드코딩된 `@media (max-width: 1024px)` 형태의 구문을 테마 유틸리티인 `${media.down('1040px')}` 및 `${media.down(theme.breakPoints.tablet)}` 구조로 변경하여 브레이크포인트 일관성을 확보했습니다.
* **인라인 스타일 제거**: `FriendItem.tsx`, `ScheduleItem.tsx`, `SharedScheduleItem.tsx` 내부에 선언되어 있던 레거시 인라인 스타일들을 전부 별도의 `.style.ts` 파일로 분리하여 Styled Components로 재구현했습니다. 이를 통해 컴포넌트 마운트 성능을 개선하고 코드 가독성을 높였습니다.
* **레이아웃 버그 수정**: 모바일 기기에서 불필요하게 중첩 적용되던 패딩 값을 `defaultAppLayout.tsx`에서 제거하여 화면 양끝이 잘리거나 깨지는 현상을 해결했습니다. 투두 상태창(`TodoStatus.tsx`)의 빈 메시지 텍스트가 모바일 가로폭을 초과하는 문제를 `<br />` 태그 대응을 통해 깔끔하게 수정했습니다.
