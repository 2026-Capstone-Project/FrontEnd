# [2026년 06월 22일] 임시 일정/할 일의 로컬 상태 관리 최적화 및 투두 카드 웹 접근성 개선

오늘 우리 "Calio" 팀은 캘린더 내에서 발생하는 임시(Draft) 일정 및 할 일(Todo)의 상태 관리 정합성을 높이고, 사용자 경험(UX)과 웹 접근성(A11y)을 강화하기 위한 버그 수정 및 리팩터링 작업을 진행했습니다. 

생성 중인 임시 데이터가 불필요하게 서버에 수정 요청(PATCH)을 보내지 않도록 방어 코드를 작성하고, 모달을 닫을 때 로컬 상태에서 안전하게 정리(Cleanup)되도록 로직을 개선했습니다. 또한, 투두 카드의 삭제 버튼을 시맨틱한 HTML 태그로 변경하여 스크린 리더 지원 및 키보드 네비게이션을 개선했습니다.

## 🌿 Branch: bugfix/#120

### [Yeonjin Kim] feat: button으로 감싸기 처리
**Yeonjin Kim** 개발자는 기존에 단순 SVG 아이콘(`Trash`)에 `onClick` 이벤트를 바인딩하여 사용하던 투두 카드 삭제 영역을 시맨틱한 `<button>` 태그로 감싸는 마크업 개선 작업을 진행했습니다. 

이 변경을 통해 키보드 포커싱이 가능해져 웹 접근성(A11y)이 크게 향상되었으며, `aria-label`을 추가하여 스크린 리더 사용자가 어떤 할 일이 삭제되는지 명확히 인지할 수 있도록 지원합니다.

#### 주요 변경 코드:
```typescript
// src/features/Todo/components/TodoCard/TodoCard.style.ts
export const DeleteButton = styled.button`
  display: inline-flex;
  align-items: center;
  justify-content: center;
  padding: 0;
  border: 0;
  background: transparent;
  cursor: pointer;
`
```
```typescript
// src/features/Todo/components/TodoCard/TodoCard.tsx
<S.ButtonWrapper>
  <PriorityBadge priority={priority} />
  <S.DeleteButton
    type="button"
    aria-label={`${title} 삭제`}
    onClick={(event) => {
      event.stopPropagation()
      handleDelete()
    }}
  >
    <Trash color="#c5c5c5" />
  </S.DeleteButton>
</S.ButtonWrapper>
```

### [Yeonjin Kim] fix: 임시 일정과 할 일 로컬 삭제 처리
**Yeonjin Kim** 개발자는 캘린더에서 일정 및 할 일을 생성할 때 발생하는 로컬 상태의 정합성 문제를 해결했습니다. 

기존에는 새로 생성 중인 임시 이벤트(`isTemporary`)가 모달을 닫거나 수정할 때 서버에 불필요한 `PATCH` 요청을 보내거나 로컬 상태에 그대로 남아있는 버그가 있었습니다. 이를 해결하기 위해 `CalendarEvent` 타입에 `isTemporary` 플래그를 도입하고, 각 훅(`useSchedulePatch`, `useTodoFooter`, `useTodoEditorForm` 등)에서 해당 플래그를 감지하여 영속화되지 않은 데이터에 대한 불필요한 API 요청을 차단했습니다. 또한, 서버 저장 완료 후 임시 ID가 실제 ID로 교체될 때 `isTemporary` 플래그를 `false`로 업데이트하도록 동기화 로직을 보완했습니다.

### [Yeonjin Kim] style: 호버 시 pointer로 마우스 커서 변경
**Yeonjin Kim** 개발자는 투두 카드의 삭제 버튼 영역에 마우스 호버 시 커서 스타일이 `pointer`로 명확하게 표시되도록 인라인 스타일을 보완하여, 사용자가 해당 영역이 인터랙션 가능한 요소임을 직관적으로 인지할 수 있도록 개선했습니다.

#### 주요 변경 코드:
```typescript
// src/features/Todo/components/TodoCard/TodoCard.tsx
<S.DeleteButton
  type="button"
  aria-label={`${title} 삭제`}
  onClick={(event) => {
    event.stopPropagation()
    handleDelete()
  }}
  style={{ cursor: 'pointer' }} // 호버 시 커서 스타일 보장
>
  <Trash color="#c5c5c5" />
</S.DeleteButton>
```

### 시니어 개발자 총평:
오늘 진행된 `bugfix/#120` 작업은 캘린더와 투두 서비스의 핵심인 **'상태 관리의 안정성'**과 **'사용성(A11y/UX)'**을 모두 잡은 훌륭한 작업입니다. 특히 클라이언트 사이드에서 임시 ID를 발급하여 낙관적 업데이트(Optimistic Update)나 드래프트 상태를 유지할 때 발생하기 쉬운 사이드 이펙트를 `isTemporary` 플래그 도입을 통해 깔끔하게 방어해 냈습니다. 

또한, 단순한 기능 구현에 그치지 않고 HTML 시맨틱 태그를 활용한 마크업 개선(`button` 래핑 및 `aria-label` 적용)을 동반한 점은 제품의 퀄리티를 한 단계 높이는 좋은 접근이었습니다. 앞으로도 상태 플래그를 활용한 예외 처리 시 메모리 누수나 불필요한 렌더링이 발생하지 않는지 지속적으로 모니터링해 나갑시다. 수고하셨습니다.
