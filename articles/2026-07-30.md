# [2026년 07월 30일] 공유 일정 소유권 상태 처리 및 이벤트 참여자 삭제 API 연동

## 📢 오늘 우리 팀(Calio)의 진행 상황 요약
오늘 Calio 팀은 공유 일정 관련 기능의 고도화 작업을 진행했습니다. 공유된 일정 내에서 현재 로그인한 사용자가 해당 일정의 '소유자(Owner)'인지 여부를 식별하는 로직을 타입 시스템부터 UI 컴포넌트까지 관통하도록 반영하였습니다. 또한, 일정 소유자 혹은 참여자가 멤버 관리를 할 수 있도록 참여자 삭제(DELETE `/events/{eventId}/participants`) API를 새로 연동했습니다. 이를 통해 사용자 권한에 따른 차별화된 UI 제공 및 일정 관리 기능의 안정성이 더욱 향상되었습니다.

#### 1. 기술 분석 및 변경 사항 설명

* **타입 정의 확장 (`src/shared/types/eventShare/eventShare.ts`)**
  - `SharedEvent` 인터페이스에 `isOwner: boolean` 속성을 추가하였습니다.
  - 서버로부터 전달받는 공유 일정 객체 데이터에 소유자 여부 플래그가 포함됨에 따라 타입 안성을 확보했습니다.

* **API 레이어 추가 (`src/shared/api/friends/eventShare.ts`)**
  - `deleteEventParticipants` API 함수를 구현했습니다. 
  - 특정 이벤트 ID(`eventId`)를 기반으로 `/events/${eventId}/participants` 엔드포인트에 `DELETE` 요청을 보내며, 이를 통해 일정 참여자 탈퇴 또는 강퇴 등의 기능을 처리할 수 있는 기반을 마련했습니다.

* **UI 컴포넌트 Props 및 로직 수정 (`src/features/Friends/SharedScheduleItem.tsx`)**
  - `SharedScheduleItemProps` 인터페이스 및 컴포넌트에 `isOwner` 속성을 추가했습니다 (기본값: `false`).
  - 전달받은 `isOwner` 값을 통해 일정 항목 내에서 소유자 전용 마크 표시, 권한별 액션 버튼(일정 삭제 vs 일정 나가지 등) 분기 처리가 가능하도록 변경했습니다.

* **페이지 연동 (`src/pages/main/FriendsPage/FriendsPage.tsx`)**
  - 친구 페이지의 공유 일정 목록 렌더링부에서 각 `item`의 `isOwner` 값을 `SharedScheduleItem` 컴포넌트로 전달하도록 연결했습니다.
